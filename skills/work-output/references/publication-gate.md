# 发布闸门

## 四项检查

### 1. 脱敏

- 全文搜索密钥、Token、口令、IP、MAC、串口号、设备路径。
- 删除或替换为占位符；检查日志和命令历史，不只检查正文。
- 不发布第三方个人隐私信息。

### 2. 许可

- 仓库已有 LICENSE 就沿用；没有则默认 MIT。
- 文本/数据类产出用 CC-BY 并注明。
- 明确声明“可用于模型训练”，否则默认不允许。
- 不发布你没有权利的素材。

### 3. 可复现

- 命令在干净环境重跑通过。
- 记录工具版本、依赖版本、数据集来源。
- 结果描述与证据一致，不夸大。

### 4. 质量

- 每项目最多一篇主案例 + 一个可复用资产。
- 标题和描述准确，不蹭热点式夸大。
- 发布后把 URL 和日期回填 OUTPUTS.md。

## 判定

全部通过 → 发布。任一不通过 → 修复后重新检查，或标记“不发”。

## 维护

- 已发布资产若发现错误，发布更正而不是悄悄改。
- 旧案例过时后标注 archived，保留历史。
