# 案例草稿

## 触发条件

同时满足才写，默认不自动写：

- OUTPUTS.md 公开轨存在状态为“可发布”的候选。
- 用户表达对外展示意图（知名度、分享、求职、开源）。

## 模板

```markdown
标题：<一句话说清结果，含关键数字>

摘要：<2-3 句，让陌生人看懂>

背景问题：<不依赖对话上下文>

方案与取舍：<选了什么、为什么、放弃了什么>

证据与结果：<命令、数据、仓库链接>

教训：<下次遇到 X 先试 Y，因为证据是 Z>

链接：<仓库/文档/数据集>

脱敏声明：<已检查密钥、Token、IP、个人信息>
```

## 规则

- 每项目最多一篇主案例草稿。
- 草稿不算已发布；发布前再过 publication-gate，等用户批准。
- 读者是陌生人，不是合作过的同事；结论必须有证据支撑。
- 第一人称可以，但不能夸大；平台和发布时间由用户决定。
