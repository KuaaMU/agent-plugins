# 资产索引 —— 长程攻坚要用什么、按什么顺序

> **这份索引存在的理由**：那次攻坚的全部教训都已经被写进了若干 skill、脚本和文档里，
> 但**它们彼此不引用**。下一个 agent 落地时不会自动知道"先做家族审计、再做对标、最后才动性能"。
> **没有索引的资产等于没有资产。**
>
> 来源：一次真实的长程攻坚战役的事后复盘与第一手产物（已去标识化）。
> **下面每一条都对应一次真实损失，不是设想。**

---

> **“为什么是这些资产”**（七条核心原则 + 一次生成性检验）在**仓库文档**里——
> 那是仓库的东西，**不随本 skill 安装**，所以这里不写路径。（skill 内不出现仓库路径，这条有机械检查兜着。）
> 本索引只回答一件事：**用哪个资产、按什么顺序。**

## 1. 场景路由：什么任务，加载什么

| 任务形态 | 加载 | 为什么 |
|---|---|---|
| **单一硬指标、多天/多周、≥5 个改生产代码的实验** | **`long-horizon-attack`**（本 skill）+ `adaptive-mission` | 前者防六类失效，后者管流程与漂移。**两者缺一不可** |
| 接手一个已有算子 / 某个形状段性能不达标 | **`execution-family-design`** | **先问"这个形状为什么由它算"**，再谈优化 |
| 任务第 0 天，或**第一个用例失败时** | **`upstream-recon`** | 找"同形状有没有人用另一种安排通过" |
| 上板采集与瓶颈判定 | `ops-profiling`（**先读它的量纲警告**） | §8 有一处已更正的量纲错误 |
| 要选优化策略 | `evolution-strategies`（**先读它的护栏**） | 61 条策略库天然助长策略跳跃 |
| 检视生产代码 | `<代码检视 skill>` | **它有能力做控制流可达性分析**——见 §3 |

## 2. 失效 → 资产对照（查表用）

| 失效 | 症状（**它在现场长什么样**） | 防它的资产 |
|---|---|---|
| **A 框架锁死** | 一直在推进，但失败用例的名字从没变过 | §4.3 **停滞触发器**：同一失败集合连续 3 轮未移动 ⇒ 停止开实验 |
| **B 自证偏差** | 拿了个数字，没核对它的定义式/单位/哪一臂 | §2 硬规则 2.1–2.4；`ops-profiling` 量纲警告 |
| **C 目标漂移** | 说不出"我从哪出发、什么已被证伪" | §1 锚定 + `TASK_ANCHOR.md`；`adaptive-mission` 的 STATE/TRUTH |
| **D 对标缺失** | "同族算子不适用于我"——而给不出机制 | §6 + `upstream-recon` |
| **E 装置失效** ★ | **"平坦""中性""无差异"——看起来像一次干净的否定结果** | §3 装置门 + `scripts/probe_liveness.sh` |
| **F 门语义失效** ★ | 性能门满分、假加速；精度门绿灯 | §3.4 / §3.5；`review-rubric` 的**量级合理性上界** |
| **G 证据强度失配** ★ | "已实测"其实没测；结论被复制后等级升了 | §2.5 / §2.5.2 + `scripts/claims_lint.py` |
| **判别力失效**（横跨 E/F/G） | **一个检查，在被找的东西不存在时也会变绿** | **§3.0 判别力检验**——先问"它会怎么变绿" |

★ = 那次攻坚代价最大的三类，也是常规纪律**全部拦不住**的三类。

## 3. 三个"本可以救我们"的事实

1. **`<代码检视 skill>` 本来就会做某次探针 那个检查。** 它的真实检视记录里有一条逐行追踪更早的
   `return`、证明"四条路径全部覆盖后，该分支永不执行"。**能力和工具一直都在，从没对探针分支跑过。**
2. **证据一直在我们自己手里，而且被读反了。** 邻带 A/B 实测「**A 相对 B 慢 40 %**」，
   被引用成"+40 %"后主语丢失，于是**支持 SIMD 的证据被当成反对它的证据**——代价是整条路由。
3. **一个 全部通过 的兄弟算子的存在性证明，在失败前 1 天就被读到了。**
   它把**整段相邻尺寸**交给了另一种执行安排——而那个尺寸段在我们这边走的是另一条路径。
   它被一句"不同算子，不适用"打发。

## 4. 第 0 天：**从任务书到第一个实验**（编排者照着做）

> **输入**：任务书。可能**只有**任务书。
> **产出**：一份 `TASK_ANCHOR`、一份空台账（`CLAIMS.jsonl`）、一个 `state.json`、
> 以及**一个被证明生效的装置**。
> **门**：第 7 步之前**不许跑生产代码**；第 7 步之前也不许"先试试看"。

| # | 做什么 | 产出落在哪 | 由哪条规则推出 | **跳过它的现场长相** |
|---|---|---|---|---|
| 1 | 逐字抄验收条件；写明**我无权改的部分**（并写下"我没有"） | `TASK_ANCHOR` §1–2 | 4 外置性 | 你能把目标改写成更容易达成的说法，且没人拦得住 |
| 2 | 记**起始点**：真实站位 + commit + 产物哈希 + **失败集合逐例列名** | `TASK_ANCHOR` §3 | 5 差距即进展 | 三周后说不清"从哪出发、什么已被证伪" |
| 3 | ★ **读判据 / 用例 / 验收脚本本身**——它们是外部给的，是**被测对象** | `TASK_ANCHOR` §2「判据已知脆弱性」 | **1.6** | 花好几轮去修一个**谁都过不了**的门 |
| **3b** | ★ **拿参考实现或精确解，跑一遍同一道门** | 一行结论：**这门可满足吗** | **1.6** | 同上。**这一步不需要你写一行代码**，成本一次运行 |
| 4 | 每条判据给**两个**样本：已知应通过 + 已知应报错 | `TASK_ANCHOR` §2 | **3.0.3** | 假红——去修一个根本没坏的东西 |
| 5 | **家族审计**：每行问"这个形状为什么由它算"，标 假设/已验证 | `TASK_ANCHOR` §4 | 1.1 / `execution-family-design` | 一条路由跑了两年，没人问过它为什么在这 |
| 6 | **对标**（强制时点 a）：①兄弟算子 ②自己邻带 A/B ③文档 ④竞品 | `TASK_ANCHOR` §6 | 6 / `upstream-recon` | 直到**第 12 天**才做第一次上游扫描 |
| 7 | 建 `CLAIMS.jsonl` + `state.json`；两个 lint 各跑一次**空转** | 两份空文件 + 两个绿灯 | 2.5.1 / 1.5 | 结论只活在散文里；缺口与趋势散在三份文档里 |
| 8 | **多写者的话：先确认锁**（锁是唯一互斥判据，占用检查不是） | 一行：锁在哪、谁持有、何时到期 | **3.7** | 两个写者同时占设备 ⇒ **该次测量作废** |
| 9 | 确认**度量衡**：每个要用的指标写下 定义式 / 单位 / 是否以 1 为界 | `TASK_ANCHOR` §2 | 2.1 / 2.4 | 量纲错误悄悄扩散到六处 |

**两条不要跳**：

- **第 3b 步**把"我们的东西不准"和"**这道门谁都过不了**"一刀切开，**不需要你写一行代码**。
  第二次战役的账单：1200 条判据报 708/492，三方比对后**真缺陷为 0**。
- **第 6 步**一旦第 0 天不做，往往就**再也不会做**了。

> **从这里往后**：每轮的固定动作见 §5；锚定档的机器形态见 `references/state.md`。

## 5. 每轮闭环（贴在墙上）

```text
1. 假设（可证伪、写下来）
2. 预注册：预期值 + 什么结果算否证 + 若机制是"做更少的工作"则声明
3. 检查设备 / 树 / 二进制 / 锁
4. ★ 判别力检验：如果被找的东西存在/生效，这个检查会怎么变绿？
5. ★ 装置门：证明探针生效（结构 / 廉价行为 / 内核名直方图），证据入档
6. 精度门 → 性能门（顺序不可换；工作减少型探针尤其）
7. 配对或对照测量（对照只证可复现，不证有效性）
8. 结论五选一：promote / refute / inconclusive / blocked / ★ INVALID
9. 失败先归档再回退；归档后立刻 `wc -c` 校验非空
10. 抄下此刻的失败集合（逐例列名），更新 §4 计数 + 跑一次 claims_lint
11. 更新台账与锚定；若触发 §4/§5/§6 的强制动作，立刻执行
```

## 8. 一句话

**这套资产不是"总结出来的经验"，是"用一次失败换来的检查表"。**
其中最值钱的三条，对应的是**常规纪律全部拦不住**的三类失效：
**装置失效**（跑没跑过）、**门语义失效**（绿灯证明了什么）、**证据强度失配**（声称的强度超过做过的动作）。

> **判别力检验**（§3.0）是这三条的共同根：
> **如果我要找的东西存在 / 生效 / 发生了，我这个检查会不会变绿？**
> **答不上来，它就没有判别力，它给出的任何读数都不是证据。**
