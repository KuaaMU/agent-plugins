# §2 证据台账（L2 权威正文 · 下：结构与外部证据）

> 本文件是 §2.5.2–§2.7 的权威正文。

## 2.5.2 三条借自外部成熟方案的结构

背景：横幅是散文，**它不传播**——假结论同时活在三处互不引用的副本里。
下面三条给的是"**记什么**"，不是"自动帮你记"（都是约定 + 人工登记 + lint）。

**(a) 依赖网络（TMS）**：记 justification，base fact（前提，无需理由）与
derived fact（推理结论，必须有理由）分开；前提被推翻时沿依赖边传播撤回。
落地：台账 `derived_from` 列；追问每一行"这条结论是哪几条推出来的？
其中哪条其实是没理由、被直接当成前提的？"
真实代价："探针真的跑了"是从未声明的隐含前提——它不是结论，
所以没人给它标等级，也没人检验它。

**(b) 双时间轴**（valid time vs transaction time）：旧事实被 `invalidated`，
而不是被删除。落地：`valid_from` / `invalidated_at` / `invalidated_by`
（指向推翻它的那条证据的 id）。

**(c) 取代语义（ADR）**：修正写成**新条目**，旧条目状态改为
`superseded by C-0yy`，而不是在旧文里加散文横幅。

## 2.5.3 单一权威来源

多处出现的量（计数、行号、哈希、阈值、归因）**只允许一处写**，
其余处引用；改完后全仓 `grep` 旧值必须为空。
`grep` 防残留**不防漂移**——两处改成不同说法时旧值已不存在，
那种只能靠"只有一处能写它"防住。
最省事的形态：**让量由权威处导出**（如计数以脚本实测输出为准，
三处引用与实测一致，没有一处是手工维护的）。

## 2.5.4 结论随身携带作用域限定词

结论强度**不得超过**证据覆盖范围。"这条路径没有余量"≠"这个问题没有余量"；
"在我们跑过的那几个用例上"不能省略。**省略限定词不是简洁，是加息。**

## 2.5.5 载重结论附重建命令

`test -f` 只证明文件在，不证明结论能重算。
判据：把原始数据交给另一个人，他**只跑那一条命令**，能否得到同一个数？
答不上来 ⇒ 等级不能超过`未受攻击`。

## 2.6 引用外部实现先核验可读时间窗

写"早就该去读它"之前，先查 artifact 的 `created_at`。
在你失败之后才出现的对手，**不能**用来证明你检索不力。
存在性断言写明**在哪个仓、哪个路径**核验的：
A 仓 `git cat-file` 失败只说明 A 仓没有，不说明上游删了它；
用"能否重新获取"（`git fetch <url> <ref>`）判生死，不用"我手上还有没有"。
**否定结论要两个独立通道**：同一个 API 的五次调用是**一次**；
检索索引 / 通用搜索 / 直接取原物 / 问人——换通道才算数。
真实代价：arXiv 检索五种查法全 0 命中写下"查不到"，换一个通道一次命中——
五种查法走的是**同一个通道**（对标题里的点号失明）。

## 2.7 外部 artifact 读到当场落盘

完整闭环：读到 → 落盘（源文件 + 二进制进
`evidence/<gate>/<date>_<topic>/external/`）→ 记哈希
（sha256sum + commit / ref / 获取命令与 URL）→ 台账登记 →
lint 时 `test -f` 校验。
判据：**"这条信源，一周后还拿得到吗？"** 拿不到的，读到当场归档。
真实代价：读了竞品 MR 只留摘要、源文件未落盘，一组对照读数一度
只能降级为"未验证"；靠配对复测救回来是运气——当初执行闭环第 ② 步
就根本不需要"救"。
