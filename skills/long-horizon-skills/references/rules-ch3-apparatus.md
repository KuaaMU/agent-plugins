# §3 装置门（L2 权威正文）

> 本文件是 §3 的权威正文。**本节是唯一能拦住"装置失效"的环节**：
> 预注册抓不住（预测可以照写）、A/B 对照抓不住、精度门抓不住、
> 独立复核也不一定抓得住（复核者读的是同一份假数据）。
> 它要的不是"更好的测量纪律"，而是**对装置本身的、与测量无关的检查**。

## 3.0 判别力检验（本节所有条目的共同根）

任何检查、探针、编码、指标或"验证"，先问：
**"如果我要找的东西存在 / 生效 / 发生了，我这个检查会不会变绿（或变红）？"**
答不上来 ⇒ 这个检查没有判别力，它的任何读数都不是证据。

更尖锐的问法：**"在最坏情况下——它没跑、它不存在、它失败了——
我这个检查的输出，会不会和成功时一模一样？"** 会 ⇒ 判别力为零。

判别力缺失的四种典型形态（那次攻坚各发生过）：
- **探针够不着**：分支在无条件 `return` 之后 ⇒ 两臂跑同一份代码；
- **编码分不开**：`(true,≈0)` 与 `(false,≈1000)` 编成同一个整数 ⇒ 相反结论都"有据"；
- **检查跑在它不可能成功的地方**：在从未 fetch 过该 MR 的仓里 `git cat-file`；
- **读数不可区分**：`grep -c 'FAILED'` 对**空日志（没跑）**与**跑了且全过**给同一个 `0`
  ⇒ 一次根本没执行的精度门被读成绿灯。

**判别力检验是零成本的——它只是一句话。**
一个永远返回"不存在 / 无差异 / 0 个失败"的检查，必须先被证明
它能返回"存在 / 有差异 / 真的跑了"。
最省事的落地：给每个"计数/枚举"型检查配一个"确实跑了"的计数器
（`grep -c '^\[ RUN \]'），`ran == 0` ⇒ 判 `INVALID`，不得判 `PASS`。

### 3.0.1 汇总行必须携带分母

`pass=k` 不同时给 `total` ⇒ `total=0`（没跑）与 `total=k`（全过）不可区分。
所有汇总写成 `pass=k / total=n`，`n==0` 时显式报警。

### 3.0.2 / 3.0.3 判据的双样本

每条判据上线前必须跑过**两个**样本：**已知应当通过**的（阳性）+
**已知应当报错**的（阴性）。只有前者，它可能是个常量；
只有后者，它可能在惩罚正确（真实事故：为防空统计假绿加的
`validCount > 0`，在输出逐位相等时也开火，一次产出 134 个假红）。

## 3.1 探针生效性四法（证据入档）

| # | 方法 | 成本 |
|---|---|---|
| 1 | **结构**：跑 `scripts/probe_liveness.sh`——抽函数体，检测插入点前所有 `return` 及其守卫；若守卫被目标输入完全覆盖 ⇒ `INVALID` 并打印守卫原文+行号 | 一次运行 |
| 2 | **行为·廉价**：探针分支内加可观测副作用（如 `fprintf(stderr,"[PROBE-FIRED]")`），跑目标用例 grep | 一次构建+单例 |
| 3 | **行为·决定性**：profiler 采目标用例，读内核名直方图；探针臂应出现探针所选内核 | 一次采集 |
| 4 | **差分·零成本**：找**只有新路径能影响**的用例看它是否移动；找不到 ⇒ 探针作用域与用例集不交，本身就是警报 | 零 |

**④ 优先试**（唯一零成本），找不到才退到 ②/③。
`probe_liveness.sh` 自己必须先通过验收：拿一个已知分支不可达的探针跑，
必须报 `INVALID` 并指出那条更早的 `return` 的行号——跑不出这个结果，
脚本就是装饰品。

## 3.2 结构差异推论

两臂实测差异**小于**两臂实现的"结构差异"（线程数/片上预算/启动次数/
数据布局）⇒ 先怀疑探针，不要相信结果。结构上完全不同的实现
不可能打平到 1% 以内——打平意味着它们是同一份代码。

## 3.3 对照臂只证可复现

A / A2 逐例一致**只**证明测量可复现；**一份死探针完美可复现**。
A/A2 一致**不能**用作探针生效的证据。

## 3.4 门语义：绿灯证明"所走路径正确"，不证明"走的是哪条路径"

- 精度门通过 ⇒ 被执行的代码算对了；**不**说明被执行的是探针分支。
- 性能门通过**不校验数值** ⇒ "做更少工作"的改动会产生惊人假加速且整带通过。
  真实事故：把小尺寸用例重路由到**算错**的内核，得一个数量级假加速；
  **量级是唯一报警的东西**，而量级恰恰也是真突破会有的东西。

## 3.5 工作减少型探针

机制是"做更少的工作"（提前退出/缩小覆盖/跳过列/降精度）的探针，
必须在预注册里声明，并**无条件先过精度门再看性能**。
便宜的上界检查："这会不会让我们比一个已知能通过的实现还快得多？"
会 ⇒ 先去找丢了什么工作。

## 3.6 无生效证据不得判 refuted

证明不了探针生效时，结论只能记 **`INVALID`**，不得记 `refuted`。
`INVALID` 不进 §4 的失败计数（那次实验没发生），但**必须**进 §7 的自我否证清单。

## 3.7 并发：锁是唯一的互斥判据

"检查的那一刻空闲"证明不了"用的那段时间空闲"。
占用检查只能用来**发现陈旧锁**，不许用来绕过锁；锁要表达"谁持有、何时到期"；
短任务不排在长任务后面。
