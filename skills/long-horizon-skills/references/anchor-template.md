# TASK_ANCHOR.md — 填写模板

> 在**写任何代码之前**建立；此后每 ≤5 个实验或每 24 小时**重建一次**。
> **重建 = 不看旧总结，从原始证据重写。**（旧版另存，用于对比"我什么时候改变了看法"。）
>
> **本模板对应 SKILL 的节号**：§1 锚定 / §2 台账 / §3 装置门 / §4 失败计数 /
> §5 耗尽 / §6 对标 / §7 自否证 / §8 审计 / §9 完成判据 / §10 每轮闭环。

## 3. 起始点（这是最容易被丢掉的一节）

| 项 | 值 |
|---|---|
| 当前实测站位 | <例如 离目标差 2 个用例> |

| 二进制哈希 / 构建产物 | `<hash>` |

> **失败集合是本表最重要的字段**——它是 §4 停滞触发器的唯一输入。
> 每次实验后都要重抄一遍；**名字逐一对得上、缺口没缩小，就是没动。**
>
> **每轮实验前只读一屏 —— 而那一屏现在由工具渲染，不再手工维护。**
> 把本表第 3 节（失败集合/缺口）、第 4 节（当前框架）的**当前值**提交进 `state.json`
> （见 `references/state.md`），`--show` 就是那一屏：
>
> ```bash
> python3 scripts/state_patch.py --show --state state.json    # 末尾就是 4.6 那一行算术
> ```
>
> **为什么必须这么办**：硬规则 `4.6` 要求缺口与它的趋势出现在同一屏上。
> 这些数散在三份只增不减的文档里，4.6 就永远不会开火，只会变成又一条「读起来很对」的意图。
>
> **⚠️ 不要再手工维护第二份「一屏」。** 曾经有一个 `FRAME.md` 承担这个角色，**已并入 `state.json`**——
> 它的字段是 state schema 的真子集。两份并行的状态件就是硬规则 `2.5.3` 要防的东西：
> **它们会漂，而且漂了没人知道**。`--show` 与 `state.json` 不会漂——一个是另一个的渲染。
>
> 其中"已排除的路径"**每条必须带失效标记**。这一条借自外部的一篇工作——
> **SKILL.state: Scalable Long-Horizon Agent Skills**（arXiv `2608.26263`，`accepted at EMNLP`，
> 2026-08-26 提交；核验方式：`firecrawl scrape https://arxiv.org/abs/2608.26263`）——
> 它用"补丁中置 `null` 即删除"来表达同一件事：**过时的前提要被显式删掉，而不是留在文里等人重新判断**。
> 本仓取的比这一点多：**固定 schema 的状态对象 + 稀疏补丁 + `null` 删除 + 校验门**，
> 落在 `state.json` / `scripts/state_patch.py` 上（见 **`references/state.md`**）。
> **不取**的只是它的 runtime 与平台适配器——本仓是一组检查，不是执行引擎。
> 只增不减的排除清单，会让每一轮都重新判断"它还算不算数"——
> **一条没有失效标记的条目，就是一个还在暗中生效的假设。**

## 4. 当前框架 —— **标注它是假设还是结论**

| 形状/范围 | 由谁算 | 为什么 | 状态 |
|---|---|---|---|
| <某尺寸段> | <某路径> | <历史原因 / 实测> | **假设 / 已验证** |
| ... | | | |

> **本节是核心。** 凡"为什么"一栏写的是"一直如此""历史沿用""继承来的"，
> **该行状态必须是"假设"**，并进入第 5 节。
>
> 对每一行问一次：**"这个形状为什么由它来算？"** 答不上来就是假设。

## 5. 未验证假设清单

| # | 假设 | 若为假会怎样 | 怎么证伪 | 代价 |
|---|---|---|---|---|
| 1 | <例：某个尺寸段用某个执行模型是对的> | <整个方向错> | <对标 / 换表述测一次> | <小> |
| 2 | **被测对象的性质**（输入分布、对角/非对角量级、用例形状） | <整轮实验的前提崩> | **读测试生成器与用例表原文**（一次 grep） | 极小 |
| 3 | <邻居的"不适用"判断：某兄弟算子的做法不适用> | <错过一整条路径> | 给出**它为什么不适用**的具体机制，或直接测一次 | 中 |

> **第 2、3 行是两个真实事故的直接产物**：
> 前者（"随机矩阵必有近零对角元"）被写进预注册并得到复核者背书，而**用例生成器给对角加了偏移**；
> 后者（"兄弟算子的向量段不适用于我"）一句话打发掉了一份**存在性证明**，而竞品取胜的方式正是它。

## 6. 对标（§6 强制）—— 按**可得性**排序，不是按"像不像竞品"排序

> **前提**：竞品的实现在冲线之前**通常不可得**（交付物常在验收后才公开）。
> 所以本表的填写顺序是 **① → ② → ③ → ④**，**做到哪一层有结论就停**。
> **④ 不得放入关键路径。**

| 时点 | 优先级 | 对标对象 | 它对**这个形状**怎么做 | 它的分档是推导还是手调 | **它何时可读**（created_at / 我就有） | 我是否已试 |
|---|---|---|---|---|---|---|
| 第 0 天 | **①** | <同仓 / 同上游的兄弟算子> | | | **就在我手上** | |
| 第 0 天 | **②** | <我自己邻带的 A/B（邻带是否用了另一种表述？）> | | | **已跑过，有原始日志** | |
| 第 0 天 | ③ | <公开文档 / 参考库 / 白皮书> | | | | |
| 首个用例失败时 | **①** | | | | | |
| 首个用例失败时 | **②** | | | | | |
| （不强制） | ④ | <竞品提交> | | | <时间戳> | |

> **"它何时可读"这一列是硬要求**（SKILL 硬规则 2.6）：写下任何
> "我们早就该去读它"的因果归因之前，先确认它**在你失败的时候就已经存在**。
> 真实事故：一份复盘把失败归因于"两三周没读过公开同类实现"，
> 而那份竞品 MR 的创建时间距我们读到它只有 **数小时**。

## 11. 结论台账（= `CLAIMS.jsonl`，§2.5.1）

> **载体是 JSONL，一行一条，机器读写。** markdown 表格是**派生视图**（`--render` 生成，给人看）。
> 为什么换成 JSONL：旧版把 markdown 表格当数据格式，于是"单元格内容含裸 `|` 就静默切行"
> 这一类问题**反复出现，而报出来的还是症状不是病因**（见 `scripts/claims_lint.py` 文件头）。
>
> ```jsonc
> {"id":"C-001","claim":"一句话结论","grade":"已实测","evidence":"evidence/<gate>/<date>/MANIFEST.md",
>  "derived_from":[],"valid_from":"2026-09-01","invalidated_at":null,"invalidated_by":null,"recorder":"lead"}
> ```
>
> - `grade` ∈ `已实测` / `已被独立复核` / `未受攻击` / `INVALID`。
>   **`未验证` 由 lint 算出，不要手写**（证据路径不存在时它自动降级并报告）。
> - `evidence`：**文件或目录都算**（一次实验的产物常是一整个目录）。
> - `derived_from` 是**「推导自」**；要表达**「取代」**请用 `invalidated_by`，
>   **不要**用它——否则旧条目失效时会把新条目一起标掉，而新条目正是来纠正它的。
> - `invalidated_*` 只在失效时才有值，平时留空。**不要回填历史**。

**每次重新锚定跑一次：**

```sh
python3 scripts/claims_lint.py --ledger CLAIMS.jsonl --root . --doc STATE.md --doc <复盘>
```

**它机械地判出六件事**，其中三条拦的是真实发生过的失效：

| 检查 | 拦的是 |
|---|---|
| ① id 唯一合法 + 字段集固定 | — |
| ② 证据路径存在（**文件或目录**） | **E5**：载重结论的原始日志从未入档 |
| ③ 派生文档不得升级等级 / 不得引用不存在的 id | **G1**：把"未测"写成"已实测"并复制到别处 |
| **④ 失效的传递闭包** | **G1 的传播面**：前提被推翻，下游没跟着标掉 |
| **⑤ 无支撑断言** | 某次探针的隐含前提："探针真的跑了"——既无证据也无推导来源 |
| **⑥ `invalidated_by` 悬空** | 失效引用指向不存在的记录 |

> 工具**自带 15 条自检**（阴性样本 + 逐条正样本 + 目录作证据 + 导入报病因 + 往返一致），
> 跑 `python3 scripts/claims_lint.py --self-test` 即可复核它确实会开火。
