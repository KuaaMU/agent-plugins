# §11 每轮闭环（L2 权威正文）

> 两层循环：**外循环**管任务轮（v2 自主循环），**内循环**管实验轮
> （原 §10 十一步）。外循环决定"这轮打哪"，内循环决定"这次实验怎么做"。

## 外循环：每轮只执行一个最高价值闭环

1. **REANCHOR（重锚定）**：重读 TASK_ANCHOR，不看旧总结，从原始证据重建
   （§1.2）；验证 state.json 的 frame / hash / 环境是否还成立，
   不一致先标 `stale`。
2. **读状态**：只读 `state.json` 一个对象（§1.5），不重建历史。
3. **CLASSIFY（分类）**：把当前阻碍归入契约/语义、正确性、环境/构建、
   性能关键路径、证据/状态、工程卫生；**禁止混成一个"优化问题"**。
4. **验基线**：最小可复现基线；结果与权威记录不一致先解释差异，
   不在未知基线上叠变量。
5. **ATTRIBUTE（归因）**：先回答"为什么慢/错/不稳定"，再问"怎么改"；
   关键路径账本 + 探针生效性（§3）。
6. **HYPOTHESIZE（可证伪候选）**：一条假设、一个变量、预期方向、
   目标量级、kill 线；用 `new_candidate.py` 登记；开跑前先写
   "若有效，失败集合会怎么变"（§4.5）。
7. **PROBE（分层验证）**：最小 case → 代表性集 → 全量，成本递增；
   过程证据不能替代目标环境验收。
8. **GATE（门禁裁决）**：按类别跑门禁（§3/§9）；结论六选一：
   promote / refute / inconclusive / blocked / INVALID（§3.6）。
9. **DECIDE + PERSIST**：promote / iterate / revert / park / close 五选一；
   失败也要留"失败原因 + 关闭条件 + 重开条件"；
   提交状态补丁（`state_patch.py`，`null` 删键）+ 台账条目 + EVENTS 日志。
10. **赛马复盘点**：到 N 轮（建议 5）了吗？看记分牌，kill 落后者（§12）。

只有验收口径冲突 / 不可逆高成本操作 / 目标资源缺失 /
连续失败要换目标时升级给用户，并附：当前目标、已验证事实、
已关闭路线、最小请求、默认建议。

## 内循环：每次实验的最小闭环（贴在墙上）

```
1. 假设（可证伪、写下来）
2. 预注册：预期值 + 什么结果算否证 + 若机制是"做更少的工作"则声明
3. 检查设备/树/二进制/锁
4. ★ 装置门：证明探针生效（§3 四法，差分优先），证据入档
5. 精度门 → 性能门（顺序不可换；工作减少型探针尤其）
6. 配对或对照测量（不接受单次无对照；对照只证可复现）
7. 结论六选一：promote / refute / inconclusive / blocked / ★ INVALID
8. 失败先归档再回退；归档后校验产物非空，不留未归档临时树
9. 抄下此刻的失败集合（逐例列名），更新 §4 计数
10. ★ 提交状态补丁：state_patch.py（只写变了的字段；null 删除；
    校验门拒绝时状态不动，去读拒绝原因，不要绕过）
11. 更新台账与锚定；若触发 §4/§5/§6 的强制动作，立刻执行
```

## 自主纠错：连续三次无正收益（止损）

WHEN 同一问题、同一结构连续三次满足任一 THEN 触发：
- 三次实验失败集合纹丝不动（§4.3），或
- 三次都是"战术失败"且缺口缩小量可忽略（§4.6 外推到不了），或
- 三次结论都是 `INVALID`（装置没生效，§3.6）。

触发后：停止参数扫描 → 写失败复盘（假设/已试/证据）→
只允许从**新结构假设**重开（§14 困难集 / §6 对标二选一）。
